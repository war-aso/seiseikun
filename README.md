# 商談フローチャート ビルダー

自分の商談スタイルをフローチャート化して展開できるツールです。YES/NOの分岐で内容を自由に記入でき、チャートを自在に増やせます。

## 機能

- **フローチャート作成**: ドラッグ&ドロップでノードを配置
- **YES/NO分岐**: 判断分岐で双方向フロー作成
- **ノード編集**: 各ノードの内容を自由に記入可能
- **動的追加**: ノードをいつでも追加・削除可能
- **保存・読込**: ローカルストレージへの自動保存、JSONエクスポート/インポート

## ノードタイプ

- **スタート**: フロー開始ノード（緑）
- **判断分岐**: YES/NOで分岐（青・ダイヤモンド型）
- **アクション**: 処理や状態（オレンジ）
- **終了**: フロー終了ノード（緑）

## インストール

```bash
npm install
```

## 開発サーバー起動

```bash
npm run dev
```

## ビルド

```bash
npm run build
```

## 使い方

1. 左側のキャンバスでノードをクリックして選択
2. 右側のエディタパネルでノードの内容を編集
3. 判断分岐ノードの場合、YES/NOそれぞれに次のノードを追加
4. 「保存」で自動的にローカルストレージに保存
5. 「エクスポート」でJSONファイルとして保存、「インポート」で復元
